# 99. 미결정 사항

착수 전 또는 1주차에 확정해야 하는 것들. 결정하면 이 문서에 날짜와 결정을 기록하고 해당 설계 문서를 갱신한다.

## 즉시 결정 필요

| # | 항목 | 선택지 | 비고 |
|---:|---|---|---|
| 1 | **서비스 이름** | `RootCause Stream` (가칭) / `AskToSee` / 기타 | 레포 이름과 발표 제목에 쓰인다. `AskToSee`가 프레이밍("보여달라고 묻는다")을 담지만, 검색 가능성은 낮다 |
| 2 | **1인 / 팀** | — | 팀이면 D1~D9를 병렬화할 수 있다. 일정표는 1인 기준으로 작성됨 |
| 3 | 수업 요구사항 재확인 | LLM "또는" VLM / "그리고" | 현재 설계는 둘 다 사용하므로 어느 쪽이든 충족. 단 평가기준의 "다양한 기술"에 맞춰 ablation 표를 핵심에 둠 |

- 로컬 오픈 VLM 폴백 — 외부 의존을 1개로 유지한다
- 이상탐지 모델 자체의 개선 — 선행 프로젝트의 영역
- 다품목 설비 범용화 — 검증은 RSW 1종
- 실시간 설비 제어 / 자동 정지 — 사람의 조치를 전제로 한다
- 아날로그 계기 바늘 → 정확한 수치 환산 — VLM 한계, 구간 판정으로 대체
