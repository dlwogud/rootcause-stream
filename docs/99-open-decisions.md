## 범위 외로 확정한 것 (논의 재개 금지)

- **로컬 오픈 모델(Qwen2.5-VL 등) — 채택하지 않는다.** M4 Air 16GB에서 3~4B가 한계이고
  (실측: 압축 6.6GB·스왑 3.55GB로 이미 포화), Agent 루프 품질이 부족하다.
  `claude -p` 가 추가 비용 0으로 프런티어 품질을 주므로 이유가 사라졌다
- 이상탐지 모델 자체의 개선 — 선행 프로젝트의 영역
- 다품목 설비 범용화 — 검증은 RSW 1종
- 실시간 설비 제어 / 자동 정지 — 사람의 조치를 전제로 한다
- 아날로그 계기 바늘 → 정확한 수치 환산 — VLM 한계, 구간 판정으로 대체
