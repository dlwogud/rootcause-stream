# 08. 프론트엔드 구성

Jinja2 템플릿 + HTMX + SSE + Tailwind(CDN). SPA 프레임워크를 쓰지 않는다 — 16일 안에 관제 화면과 모바일 업로드를 모두 만들려면 빌드 파이프라인이 없는 쪽이 빠르다.

구성 요소:
- **알람 타임라인** — SSE로 실시간 추가. `파생 알람 숨기기` 토글이 **"47건 → 3건"**을 즉시 보여준다. 시연 장면 ①.
- **가설 보드** — 점수 바가 증거 도착에 따라 움직인다. 각 가설의 근거 증거 id를 클릭하면 원 증거(시계열 차트 / 도면 이미지 / 사진)가 열린다.
- **추론 트레이스** — 스텝별 모델·effort·지연·토큰. **"기술을 실제로 썼다"를 화면으로 증명하는 패널.** 심사위원이 보는 순간 다른 프로젝트와 갈린다.
- **검색 모드 토글** — 매뉴얼 검색 결과 패널에 `벡터 / BM25 / 하이브리드 / +리랭커` 라디오. 라이브 ablation.


**QR 코드가 시연의 결정적 장치다.** 발표자가 폰으로 QR을 스캔 → 그 자리에서 촬영 → 업로드 → 화면의 가설 점수가 움직인다. 이 한 장면이 프로젝트 전체를 설명한다.

## 화면 3 — 모바일 업로드 (`/m/upload/{token}`)

단일 컬럼, 큰 버튼. 작업자는 장갑을 끼고 있다고 가정한다.

```
┌──────────────────────┐
│ 상부 전극 팁 선단    │
│                      │
│ 팁 끝에서 10cm       │
│ 측면 각도            │
│ 플래시 ON            │
│                      │
│ [ 📷  촬영하기 ]     │
│                      │
│ 왜 이 사진이 필요한가│
│ H1과 H3을 구분합니다 │
└──────────────────────┘
```

업로드 후 판독 결과를 즉시 표시:

```
판독 결과
  관찰: 팁 선단 버섯형 변형, 표면 산화
  분류: 마모 진행
  신뢰도: 높음
  → H1 전극 팁 마모 (0.42 → 0.91)
```

판독 실패 시: `다시 촬영해주세요 — 초점이 흐려 선단 형상을 판별할 수 없습니다` (VLM의 `unreadable_reason`을 그대로 노출).

`<input type="file" accept="image/*" capture="environment">` 로 네이티브 카메라를 직접 띄운다.

## 화면 4 — 조치 카드

```
┌─ 확정 원인: 상부 전극 팁 마모 (신뢰도 0.91) ─────┐
│                                                  │
│ 1. 설비 정지 및 전원 차단                        │
│    ⚠ 냉각수 공급을 먼저 차단하지 마십시오        │
│    📄 매뉴얼 4-1절 p.34                          │
│                                                  │
│ 2. 전극 팁 드레싱 또는 교체                      │
│    📄 매뉴얼 4-3절 p.37  [원문 보기]             │
│                                                  │
│ 조치 후 확인                                     │
│ ☐ 시험 타점 5점의 동저항 편차 < 기준             │
│ ☐ 가압력 중위수 기준 범위 복귀                   │
│                                                  │
│ [조치 완료] [효과 없음] [보류]                   │
└──────────────────────────────────────────────────┘
```

`[원문 보기]`는 citations의 `cited_text`와 페이지 이미지를 띄운다. **인용이 클릭 가능해야 "검증 가능한 AI"라는 주장이 성립한다.**

버튼 3개가 사례 적립의 `outcome`이 된다. `효과 없음`도 수집해야 메모리가 쓸모 있어진다.

## 화면 5 — 평가 리포트 (`/api/eval/runs/{id}/report`)

ablation 표 + Tier별 정확도 + 정보이득 분포 + 비용. **발표자료에 그대로 캡처해 넣을 화면**이므로 처음부터 보기 좋게 만든다.
