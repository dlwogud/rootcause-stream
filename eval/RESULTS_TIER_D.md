## 왜 실패했나 — Agent 가 아니라 케이스 설계의 결함

**① 설계자가 정한 가설을 Agent 가 한 번도 떠올리지 않았다.**
케이스는 "전극 마모 vs 냉각 불량"으로 설계했으나, 12회 중 **냉각을 언급한 것은 0회**였다.
Agent 는 일관되게 "전극 접촉 / 2차 회로 연결부 / 전압 측정선"을 의심했다.
주입한 신호가 *전압 상승*이었으므로 Agent 쪽 가설이 그 신호에 더 부합한다.
정답을 먼저 정하고 사건을 끼워 맞춘 설계자 편향이다.

**② 공개 사진은 '이 설비의 사진'이 아니고, Agent 가 그것을 알아챘다.**
웹 E2E 실행의 최종 결론:

> *"the photographs returned loose electrode tips or unrelated parts rather than the installed
> tips or the connections … Inspect the installed tip faces and the secondary joints"*

천 위에 진열된 새 전극 제품 사진을 받고 **"이것은 장착된 전극이 아니다"라고 판단해 증거로
채택하지 않았다.** 올바른 추론이지만, 곧 스톡 사진으로는 결정적 증거를 만들 수 없다는 뜻이다.

**③ 정보이득 지표의 정의가 잘못됐다.**
- 사진이 1위 가설을 *반박*하면 분포가 고르게 퍼져 엔트로피가 오히려 **커질** 수 있다
- 추론을 한 스텝 더 하는 것만으로도 엔트로피가 줄어든다

무작위 사진이 더 높게 나온 것은 이 때문이다. 엔트로피 감소가 아니라 **정답 가설에 실린 확률의
변화**를 재야 했고, '한 스텝 더(사진 없음)' 대비 차이로 비교해야 했다.

## 결론과 처리

- Tier D 는 **측정 주장에서 제외**한다. 코드와 결과는 남긴다
- 사진 루프의 가치는 다른 실측 근거로 주장한다
  - Tier A: "센서로는 못 가른다 → 가르는 관측 요청" 베이스라인 **0% → Agent 100%**
  - ablation `no_photo`: 촬영 요청을 끄면 같은 지표 **100% → 0%** (못 물어보면 단정한다)
- ②의 장면은 한계가 아니라 **환각 방어의 실제 사례**로 발표한다
  — 엉뚱한 증거를 받으면 Agent 가 그것을 알아채고 쓰지 않는다

## 다시 한다면

1. 정답 가설을 정하기 전에 Agent 를 먼저 돌려 **Agent 가 실제로 떠올리는 가설 공간**을 확인한다
2. 사진은 그 가설들을 가르는 것으로, **해당 설비의 장착 상태**를 찍은 것이어야 한다 — 실제 설비 없이는 불가능
3. 지표는 정답 가설 확률의 변화량, 대조는 '사진 없이 한 스텝 더'
