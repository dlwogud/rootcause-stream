# 외부 출처 라벨

이 디렉터리의 파일은 **이 프로젝트가 만들지 않았다.** 선행 프로젝트
`kamp-welding`(제6회 K-인공지능 제조데이터 분석 경진대회 제출물)의 산출물이고,
그 프로젝트에서 통계적으로 검증된 것이다. 정답 라벨의 출처가 외부에 있다는 것이
이 프로젝트 평가(Tier A/C)의 전제다 — `docs/05-data.md` 참조.

| 파일 | 내용 | 생성자 |
|---|---|---|
| `duplicated_block_index.csv` | 복제 구간에 속한 (작업일, idx) 쌍 | `kamp-welding/src/06_data_integrity.py` |

복제 구간은 전 공정변수가 유효숫자까지 동일한 800점 런이 4개 작업일에 반복된 것으로,
행 해시 + 최장공통런으로 사전 임계 없이 발견됐다. 전체의 26.8%이며
**2020-04-03 은 작업일 전체가 이 구간**이다.

이 구간에서 알람이 발생하지만 원인은 설비 이상이 아니라 **데이터 수집 계통 이상**이다.
→ Tier C 평가 케이스.
