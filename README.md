# RootCause Stream

> 설비 이상이 감지됐다. **그래서 작업자는 무엇을 해야 하는가?**
>
> 그 답은 센서 데이터에 없다. 매뉴얼의 도면과 현장의 사진에 있다.
> RootCause Stream은 LLM Agent가 가설을 세우고, **자기가 모르는 것을 사람에게 사진으로 요청해서** 가설을 확정한다.

2026년 LLM/VLM 기반 서비스 개발 프로젝트. (서비스명 가칭 — `docs/99-open-decisions.md` 참조)

## 한 문장

실시간 알람 스트림에서 근본원인 가설을 생성하고, 매뉴얼 도면(VLM)으로 가설을 좁히고, **남은 불확실성을 작업자에게 촬영 요청으로 전환해 사진 판독(VLM)으로 확정**하는 진단 Agent.

## 왜 LLM/VLM이 없으면 안 되는가

| 단계 | 필요한 정보 | 어디에 있는가 | 일반 프로그래밍으로 가능한가 |
|---|---|---|---|
| 파생 알람 제거 | 알람 간 인과 구조 | 매뉴얼 서술 + 공정 지식 | 규칙으로 일부만 |
| 가설 구분 | 배관·계통 연결 관계 | **P&ID 도면 이미지** | ❌ 불가 |
| 조치 절차 | 트러블슈팅 플로우차트 | **이미지 플로우차트** | ❌ 불가 |
| 가설 확정 | 전극 팁 상태, 게이지 값, 누유 | **현장 사진** | ❌ 불가 |
| 촬영 지시 생성 | "어떤 사진이 어떤 가설을 가르는가" | 추론 결과 | ❌ 불가 |

## 검증 도메인 — 저항점용접(RSW)

선행 프로젝트([`~/kamp-welding`](../kamp-welding))에서 같은 공정 데이터로 **"용접점 단위 불량 예측은 이 데이터로 불가능하다"를 다섯 겹으로 입증**했다. 공정 이상은 작업일 단위 수준 이동으로만 탐지됐다(2σ 관리도, 실제 shift 3/3, 오경보 0/5, permutation p=0.0179).
(⚠️ 2026-11-17: 그 수준 이동도 재활용된 기록 위에 있었다 — `docs/14-data-reuse-finding.md`)

**거기서 끝이었던 것이 이 프로젝트의 출발점이다.** 탐지 다음의 "무엇을 해야 하는가"는 데이터가 아니라 문서와 현장에 답이 있다.

→ 정답 라벨의 출처가 분명하다. `docs/05-data.md`의 Tier A/B/C 구분 참조.

## 결과 (2026-11-18)

같은 사건 · 같은 모델(haiku) · 같은 채점자(sonnet). 베이스라인은 알람 요약만 보고 LLM 을 한 번 호출한다.

| 근본원인 정확도 | 조용한 수준 이동 (A, 3건×3회) | 알람 폭주 (C, 8건×3회) |
|---|---:|---:|
| 베이스라인 | 0% | 26% |
| **Agent** | **89%** | **100%** |
| Agent − 신호 해석 설명 | 56% | 42% |
| Agent − 도구 (시계열만) | 56% | – |
| Agent − 촬영 요청 | 100% | – |

> ⚠️ **발견 — 정답지가 틀렸고, Agent 가 먼저 짚었다** (`docs/14-data-reuse-finding.md`)
> 선행 프로젝트는 기록의 26.8% 를 복제로 표시했지만, 실제로는 **97.2%** 가 다른 작업일과
> 수백 행씩 연속 그대로 일치한다 (순서를 섞은 대조는 2행). Tier A 의 정답을
> "원인 특정 불가"에서 "기록 재활용"으로 고치고, Agent 는 그대로 둔 채 다시 쟀다.
> 이전에 보고한 Tier A 수치(0%→100%, 촬영 요청 끄면 0%)는 틀린 정답 기준이라 폐기했다.

### 사진 요청의 효과 — Tier E (실제 용접 · 실제 사진, 다른 설비)

KAMP 데이터의 이상은 모두 기록 재활용이라 사진이 필요한 사건이 없다. 그래서 실제 용접부 사진과
인장시험 판정이 공개된 데이터셋([RSW Insights](https://doi.org/10.17632/rwh8kjzdch.3), CC BY 4.0)으로 쟀다.
날림 29건 + 같은 설정값 정상 29건 (개발용 4건 제외) — `eval/RESULTS_TIER_E.md`

| 촬영 요청에 돌려준 것 | 정확도 | 날림 맞힘 |
|---|---:|---:|
| 그 용접의 사진 | 48% | 17% (5/29) |
| 반대 판정 용접의 사진 | 33% | 0% |
| 응답 없음 | 41% | 0% |

- **사진 내용이 결론을 바꾼다** — 맞는 사진 vs 바꿔치기, 사건별 짝비교 p=0.023
- 날림은 사진이 있어야만 잡힌다 (0 → 5건, p=0.063 경계). 전체 효과는 작다 — 판독기가 미세한 흔적을 잘 못 가른다
- 사진 '내용'의 효과를 재려던 Tier D 는 성립하지 않았다 — `eval/RESULTS_TIER_D.md`
- Tier C 8건은 같은 복제 기록의 다른 구간이다
- 원 자료: `eval/results/*.csv` · 감사: `scripts/91_cross_day_audit.py` · 재채점: `python3 -m eval.regrade`
- 발표자료: `deck/RootCause_Stream_발표자료.pptx` (생성: `deck/build.js`)

**데이터는 레포에 없다.** KAMP 원본과 제조사 매뉴얼은 재배포 권한이 확인되지 않아
받는 방법만 적었다 — `data/raw/README.md`, `data/manuals/SOURCES.md`.
